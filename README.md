# Vortex Tech Cybersecurity Internship 
# Week 1: Research the OWASP Top 10 Vulnerabilities

## What this is
This repository contains my Week 1 submission for the Vortex Tech Cyber Security Internship Track. The task was to research and document 5 vulnerabilities from the OWASP Top 10, explaining each one in plain language, describing how it's exploited, citing a real-world breach, and outlining a practical mitigation.

## What's inside
- `OWASP-Top-10-Research.md` — the main research document covering:
  1. Broken Access Control
  2. Security Misconfiguration
  3. Cryptographic Failures
  4. Injection (SQL Injection)
  5. Authentication Failures

  Each section includes a plain-language explanation, an exploit scenario, a real-world breach example, a mitigation strategy, plus a closing personal reflection.

## How to "run" it

No code this is a research/documentation task. Just open `OWASP-Top-10-Research.md` to read it, or view it rendered directly on GitHub.

## Note on the list version

OWASP released an updated Top 10 (2025 edition) with some category renames and rank changes since the widely-referenced 2021 list. This document uses the current 2025 categories and rankings.
